**Assignment:** `t2o-r03-search-20261010`
**Verified:** 2026-10-10
**Scope:** Official current documentation and pricing for Exa, Firecrawl, Tavily, and Scrape.do. No paid search, extraction, crawl, or scrape calls were made.

## Evidence labels and limits

**Executed** means a read-only fetch of an official docs or pricing page succeeded; it does not mean a product API was run. **Documented** means the reviewed official page states the capability or price, not that it was independently tested. **Experimental** is used only where the provider labels a feature experimental. **Unsupported in reviewed evidence** means the reviewed pages did not establish support; it is not proof the product lacks it. **Unknown** means the needed detail was not established from the pages fetched. This is a bounded documentation review: API terms, privacy terms, robots/site permissions, and several lifecycle details remain unknown. Prices and plan limits can change.

## Recommendation and adapter shape

Build **Exa and Firecrawl first**. Exa is the clearest search-plus-relevant-content path and exposes MCP alongside REST; Firecrawl adds direct scraping, site crawl jobs, cancellation/status controls, and documented account usage endpoints. Tavily is a strong later option when its credit-metered search/extract and Research task lifecycle matter. Scrape.do is a specialized fallback when a target requires proxy rotation, geographic routing, or browser rendering; its query-string token warrants careful URL redaction in logs.

Use a capability registry rather than provider-shaped conditionals throughout the app. Shared contracts should cover `search`, `extract/fetch`, `crawl`, optional `submitJob/getJob/cancelJob`, `usage`, and webhook delivery where verified. Return normalized results with source URL, provider, timestamps, content, and any provider cost/usage metadata. Capability flags must be explicit (`supported`, `unsupported`, `unknown`) so an unverified lifecycle is never represented as working. Keep provider-only controls behind typed extensions: Exa search modes/highlights and agent research; Firecrawl formats, crawl filters and webhooks; Tavily depth, credits and research tasks; Scrape.do target URL, proxy, geography and browser controls.

Avoid duplicated paid calls: choose one adapter for a canonical intent, deduplicate/cache on normalized request parameters, and do not fan out to another paid provider on a timeout unless an explicit policy authorizes that extra charge. Record provider, operation, request fingerprint, returned usage/cost, and cache/dedup decision for auditability. Do not infer equal credit units across providers.
